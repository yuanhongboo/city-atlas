# 大连、温州与日本冲绳：地标来源和表现边界

核实日期：2026-10-18。来源用于确认地名、空间关系和标志形态；本批不包含票价、开放时间、排名或即时营业状态。所有模型由 Three.js 几何构建，街区、海岸和交通路线均经过艺术压缩。

## 本轮几何检查

三城各 12 个地标、3 个浏览片区、2 个真实交通动画。固定种子、夜景材质与逐地标实体标记已加入。独立检查在 `t=0..400` 每秒检查所有 Mesh 的世界包围盒，三城均未越过声明边界或低于底座 `y=-4.8`；此记录不代替主任务的全站测试和浏览器验收。
