## 模型接口

`buildDistrictLandmark(parent, type, { x, z, baseY, scale })` 创建以局部地面 `y=0` 为基准的 `THREE.Group`，返回 `{ group, height, radius }`。`height` 是乘入缩放后的模型顶部高度；`radius` 是包围盒角点的水平半径，包含地块平台。`group.userData.localBounds` 保存缩放前的包围盒，便于检查碰撞和取景。

建筑材质复用 `scene-kit.js` 的缓存。发光属性放在 `material.userData.nightGlow`，供全图统一切换昼夜；本模块不合并几何，避免父级定位、缩放与全图合并产生重复变换。模型中不使用图片、纹理下载、网络请求或浏览器 DOM，因此可以直接在 Node 中做几何检查。
