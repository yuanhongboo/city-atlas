## 布局约定

- `x` 向东，`z` 向南。西湾的欢乐港湾、前海石位于南山以西；南山后海位于福田以西；罗湖位于福田以东；龙岗大运在东北内陆，盐田和大鹏向东南展开。
- 五组名称是浏览路线：福田中轴、罗湖街巷、南山后海、宝安前海、东部山海。它们不表示完整行政范围，也不把大运中心归入盐田或大鹏。
- 莲花山在市民中心北侧；市民中心南侧为福田中心商务区。春笋在人才公园北侧。校园仅表现粤海校区。
- 公园内湖单独建模；普通街区使用陆地检测、道路距离与地标保留区筛选，船只沿海面路线运行。
- 海岸和地形是城市印象轮廓，东部距离尤其压缩；未复刻所有港区、口岸、邻近地域陆地与真实海域范围。模型不可用于地理导航、距离测量或行政边界判断。
- 建筑轮廓、校园院楼、街区店铺、树木、车船与行人均为程序化原创几何概括。未使用遥感瓦片、第三方模型、远程纹理、品牌标识或地图 API 密钥。
