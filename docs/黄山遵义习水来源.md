# 黄山、遵义、贵州习水：地标与空间依据

本页记录 2026-10-18 增补场景时使用的来源。三个场景均为程序生成的艺术化沙盘，浏览片区不是行政区划，模型坐标不是经纬度。保留大致的山水关系与地标轮廓，缩短了远郊距离，不表示交通路线、开放状态、票价或游览安全条件。
