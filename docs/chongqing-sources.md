# 重庆模型的资料与边界

本场景是围绕渝中半岛的建筑微缩沙盘，坐标经过压缩、地标比例经过夸张，不能作为导航地图。坐标约定为 x 轴向东、z 轴向南。嘉陵江位于半岛北侧，长江位于南侧，在半岛东端朝天门汇流；台地由朝天门向半岛西侧逐步抬高。

## 艺术化处理

- 建筑、街区密度与道路是程序化概括，不逐栋复原真实城市。
- 山地使用层叠台地表达，南山一棵树为外围压缩地标，距离和山高不按真实比例。
- 长江与嘉陵江以不同低饱和色辅助阅读；实际江水颜色随季节、水位与天气变化。
- 列车、索道、游船的运行速度和轨迹用于展示，不代表运营路线或时刻表。
- 洪崖洞由多组木楼、飞檐、临江走廊与暖色窗灯表达，没有声称逐层测绘复原。
