## 模型表达

- **大学城总览节点**：用林荫广场、原创书页形公共装置、玻璃交通入口、公交候车亭及自行车停车概括大学城公共生活。它是浏览片区的节点，不是第十个行政区，也不代表某个真实地铁出入口或现行线路。
- **重庆大学虎溪校园**：独立制作红色 L 形现代图书馆、云湖水景、教学楼、运动场与树阵组合，与地图既有的重庆大学老校区模型区分。湖岸、建筑数量、运动场相对位置经过重新编排，不是完整校园复原。
- **川美虎溪与罗中立美术馆**：以低层围合院落、错落坡屋顶、彩色几何拼片墙和草地雕塑表现校园与美术馆。色块和雕塑均为原创几何设计，不复制真实壁画、馆藏作品或具体雕塑。
- **熙街**：用成排低层店面、开敞步行街、外摆桌椅、遮阳伞、屋顶露台和串灯概括街区。商店立面与外摆是风格化创作，不对应实际商户、品牌、营业状态。

## 范围与限制

这四个节点服务城市沙盘浏览。模型采用压缩比例，没有测绘精度，不提供道路导航、校内导览、完整校园边界或最新交通运营信息。大学城、重庆高新区与传统主城九区属于不同的地域和管理概念；片区浏览入口不能被解释为新增行政区。

所有建筑、路面与小品均由本地 Three.js 几何生成，没有下载照片、地图瓦片、字体或第三方模型。现行参观开放与预约条件请以对应校园和美术馆公告为准，本模型不宣称开放状态。

直接抓取“走进虎溪”入口时曾返回 HTTP 412；同站图书馆、学校简介和视觉专题的可访问内容及搜索索引补充支持本次核实，因此该单页访问失败未被当作地点不存在的证据。
