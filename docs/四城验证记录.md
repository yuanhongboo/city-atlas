深圳有一个固定中心旋转的摩天轮，其世界矩阵会随时间变化，中心位置保持不变。因此动态检查比较完整 `matrixWorld`；成都和重庆原有车辆、船只、索道同时继续检查实际位移。

四城共用检查覆盖：

- 地标 ID 集合、数量统计、片区 ID 集合及 `zone` 引用；相邻地标和片区直达入口的有效性。
- 所有地标、片区和全景的相机与目标坐标有限；地标和目标在场景边界附近。重庆、深圳、香港必须提供有效且位于边界内的片区标签位置。
- 几何顶点、索引、局部矩阵、世界矩阵、实例矩阵、实例颜色、材质颜色与材质数值均为有限值；夜景发光材质具有有效的 `emissive`。
- 底座实际底部顶点与各城市声明的 `bounds` 对齐，最低点为 `-4.8`；边界不复用固定城市尺寸。
- 标记为动态的对象拥有真实 Mesh，且在七个采样时刻中确有世界变换变化。
- 深圳、香港全部地标和重庆九区扩展地标均有可追踪到 `landmarkId` 的真实 Mesh，具有独立模型尺寸。静态合并后继续保留关联信息。

原有回归检查继续保留：成都 20 个地标、天府一街至五街的东西向道路与南北顺序、沿街建筑避让车道；重庆 27 个地标、传统主城九区且每区至少两处、大学城四点归属与关联、重庆大学新老校区分开、传统分区与现行行政区划的说明。

## 验证边界

自动检查证明数据、几何关联和采样动画有效，不证明每个建筑的视觉辨识度，也不代表线上发布已经验收。

成都旧版静态合并未保留全部地标的 Mesh 标记；重庆最初八个地标也未提供此标记。本轮保留其原有整体几何、相机与动画检查，没有把元数据存在误报为逐地标模型验证通过。

## 浏览器检查

本轮主执行方通过浏览器实际检查了以下范围：

- 深圳、香港的桌面全景。
- 香港渡轮与夜景，深圳摩天轮近景。
- 390 像素和 320 像素宽度下的手机城市切换与片区选择，320 像素宽度没有水平溢出。
- 香港目录按九龙海滨筛选得到 5 处地标，可从目录跳到环球贸易广场；深圳宝安前海的导览限定为 2 处地标。
- 香港中银大厦和深圳平安金融中心的地标链接直达；切换城市会清除上一城的 place 参数。
- 成都 20 处、重庆 27 处地标与重庆九区入口回归；城市序号总数显示为 4。
- 新城市的布局说明不含重庆专属公告链接，网页控制台未出现 error 或 warn。
- 香港海面与底座共面造成的条纹已修复，刷新后视觉复核通过。
- 深圳四座高塔和香港三座高塔的近景相机根据实际模型包围盒重新取景；中银大厦与平安金融中心桌面近景、平安金融中心 320 像素手机近景已复核，不再裁掉目标塔顶。
- 最终源文件同步到正式仓库后，`npm run verify` 和 `npm run build` 均通过。构建包 gzip 约 225.90 kB；Vite 保留既有的大包体积提示。
