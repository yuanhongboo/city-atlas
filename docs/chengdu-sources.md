# 成都场景：来源与表现边界

核对日期：2026-09-09。

## 沙盘定义

这是面向交互欣赏的程序化建筑微缩模型。x 向东、z 向南，北方为 -z。城市核心、东北熊猫基地、高新南城与更南面的天府新区保留方向关系；外围距离、建筑高度、河道曲率、道路数量和街区尺度经过压缩。模型不采用测绘比例，也不承担导航用途。

十五个交互地标分成三个浏览片区：

- 老城街巷：天府广场、宽窄巷子、太古里与 IFS、安顺廊桥、兰桂坊、九眼桥、望江楼、武侯祠与锦里、熊猫基地、文殊院、人民公园。
- 高新南城：金融城双子塔、环球中心。
- 天府新区：中国西部国际博览城、兴隆湖。西博城作为新区代表节点；“天府新区”不被替换成老城的天府广场。

底座范围为 `x=-105…105、z=-105…205`。文殊院在人民路城市中轴东侧；人民公园在天府广场西侧；金融城双子塔在环球中心东北；环球中心在天府大道西侧；兴隆湖在大道东侧。两片南城之间的距离大幅压缩。浏览片区服务导航，不声称等同于行政边界。

## 艺术化部分

- 普通楼宇、树木、窗格和竹丛由固定随机种子生成，与真实门牌和楼栋不对应。
- 广场双旋水景、太阳神鸟意象、博物馆轮廓、古建屋顶和熊猫为原创几何概括。
- 模型道路以主要轴线和街区节奏组织；江上船只及道路车辆是观赏动画。
- 新增寺院殿堂、茶社茶桌与伞、纪念碑、双塔冰花幕墙与冠顶、西博城连续屋面、兴隆湖曲面书店均为专门创建的几何模型。湖畔书店的屋面形状、科研楼位置、窗面灯光与湖岸曲率是艺术概括。
- 九眼桥道路桥采用独立开敞桥面、实体桥墩、栏杆及岸上斜坡，桥墩数量与跨度为几何概括；兰桂坊及九眼桥滨江音乐街为独立建筑模型。兰桂坊棚架、招牌、桌椅和实际商铺平面不一一对应。
- 夜景通过建筑窗格、灯笼和路灯的发光材质表达，不使用真实照明数据。

## 本模块验证

- `node --check src/cities/chengdu.js` 已通过。
- 本模块导出城市模型、十五个地标、三个片区观赏视角、与实际底座一致的边界、小地图路径、统计和时间更新函数。
- 几何数值检查无非有限顶点，世界空间包围盒为 `[-105,-4.8,-105]…[105,44.3,205]`。
- 原有三艘船和九辆车继续由 `update(t)` 更新，总动态对象仍为 12 个。安顺廊桥桥体上移并补足桥墩、入口阶梯；九眼桥桥底高 2.8，当前小船最高点约为 2.18，保留行船净空。
- 锦江扩展实例化检查为 15 个地标、3 个片区、296 个网格、156 个静态合并批次、7 种夜景发光材质；无非有限几何数值。静态合并继续保留，新增店面没有引入动态对象。
- 浏览器渲染、交互与整体视觉验收由共享应用集成后执行。
