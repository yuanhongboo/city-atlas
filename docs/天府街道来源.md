# 天府一街至五街：来源与沙盘表达

核对日期：2026-09-09。

天府一街、天府二街、天府三街、天府四街、天府五街分别作为成都地图的独立可点击地标。五条街从北向南排列，主路段沿东西方向展开，与天府大道及西侧的南北道路连成街区。

## 来源支持的空间关系

- [成都高新区融媒体：园区介绍](https://web.csp.chinamcloud.com/cms/cdgxqrmt/zwsx/cywg/yqjs/61404576.shtml)：对金融区的介绍包含环球中心，并以天府一街、世纪城路作为有关区域的南侧边界。这支持把环球中心安排在一街以北。
- [天府软件园官方介绍](https://www.tianfusoftwarepark.com/index.php/zh/component/content/article/136-news/)：核心区的介绍包含北到世纪城路、南到天府五街、西到剑南大道、东到府河的空间范围，以及天府大道、益州大道等骨干道路。沙盘据此表达高新区的街道网与园区生活，不对应具体楼栋地址。
- [四川人才工作网](https://scrcgz.com/news/1136.html)：提到天府一街到五街的高新生活，支持把这五条街作为一个连续的城市生活片区呈现。
- [四川在线：高新街区影像](https://sichuan.scol.com.cn/ggxw/202408/82586291.html)：作为街区办公、公共空间和街道人尺度的外观参考。

## 模型如何表达

每条街具有连续车道、道路中心标线、两侧步行空间、自行车带、交叉口斑马线、公交候车亭、树阵、街角座椅和沿街办公空间。每条街还保留一个不同的公共空间：街角茶座、休憩广场、园区小广场、绿地廊架、园区入口。

节点 ID 固定为 `tianfu-1st`、`tianfu-2nd`、`tianfu-3rd`、`tianfu-4th`、`tianfu-5th`。每个节点保留自己的 `roadPath`、相机、说明和相邻街道链接；非品牌化道路号柱用一到五条刻度呼应界面标签。

## 表达边界

这是一张城市印象沙盘。街道路段长度、五条街之间的间距、软件园办公楼、街角商业和公共空间均作了艺术化压缩，未核实的楼栋没有标注具体公司或总部名称。模型中的公交亭、咖啡座、雕塑、廊架与建筑数量不构成真实地址或设施清单。

为给五条街留出完整的几何空间，天府新区的西博城、兴隆湖和总部办公组团整体向南延展，树木、行人、湖岸、相机及小地图同步调整。五街东端以南保留开敞前场，使新区会展模型与新增街区不发生楼体重叠。这一压缩布局不提供测绘或导航精度。
