## 异步导航回归

对当前源码的导航函数与启动逻辑进行了受控延迟回归，检查可观察的地址、场景提交、ready 与帧循环状态：

1. 后退加载 B 时重新选择当前 A，过期 B 不提交，URL 与 A 一致。
2. 首屏加载期间后退，在最新目的地加载完成前不启动帧循环，只应用最新地址的地标与光线。
3. 快速 A/B 请求按两种相反顺序完成，均只提交最后选择的目的地。
4. 导航加载失败时保留原场景，并恢复原地标与地址。
5. 首屏过期请求失败时，继续加载已变更的最新地址，过期错误不会中断当前导航。

最近三个模型使用 LRU 缓存。释放过期模型前排除仍被其他缓存场景引用的 geometry/material，并释放 InstancedMesh 的实例资源。

## 边界

本轮不声称对全部 105 个新增地标逐一截图核验或按测绘数据复建。地理距离、山势、建筑比例和交通路径均是有明确说明的沙盘表达；照片下载与实际触屏手势没有重新做全量验收。线上部署状态以 GitHub Actions 和发布后的浏览器检查为准。
