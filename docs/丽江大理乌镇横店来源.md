# 丽江、大理、乌镇、横店：地标来源与缩景边界

核对日期：2026-10-18。内容仅支撑地名、建筑特征和大体方位；未将营业安排、票价、排名或即时活动写入地图。四个目的地都是原创程序化沙盘，地理距离、地形高度和建筑比例经过压缩，浏览片区不代表行政边界，也不用于导航。

- [云南省民族宗教事务委员会：丽江市古城区文旅品牌建设](https://mzzj.yn.gov.cn/html/2024/difangdongtai_1014/4056137.html)：核对大水车、四方街、木府、狮子山与万古楼的名称。

- [云南省农业农村厅：丽江玉湖村旧貌保护](https://nync.yn.gov.cn/html/2021/meilixiangcunjianshe-nync_0114/376172.html)：核对玉湖在丽江古城以北、雪山南麓的聚落关系。

沙盘以北为 `-z`，雪山在北，大研在南；文海位于雪山西南侧。村落、古城与雪山之间的长距离压缩为一张可漫游的场景。水车转速、索道线路与壁画图案是原创表现。

## 实现与检查边界

- 所有模型由本地几何体生成，无下载纹理和地图服务密钥。`heritage-kit.js` 只复用房屋、塔、石桥、舟等基础组合，各城地形和地标组合分别编写。
- 四城各有 3 个实际改变世界矩阵的动态对象：丽江为两水车与索道；大理为两船与索道；乌镇为两船与晾布；横店为游船、旋转设施与索道。
- 创建场景与多个动画采样时刻的包围盒检查，均保持在场景声明边界内；底座最低点统一为 `-4.8`。
- 单独 Node 场景检查的网格数为丽江 154、大理 130、乌镇 95、横店 120。该值是场景网格统计，不等同于浏览器 GPU 实测 draw call；最终浏览器检查由整合阶段执行。
