## 示意布局的边界

- 北为画面坐标 `-z`，东为 `+x`。维多利亚港保留开敞水域，九龙在北、香港岛在南；天星码头分别位于两岸。
- 大屿山、赤鱲角机场、马湾和青衣向西侧压缩摆放。青马桥两端落在马湾和青衣的小岛轮廓内，不将其画成横跨维港的桥。
- 四个分类是“港岛山海、九龙海滨、九龙街巷、离岛青马”浏览片区，方便筛选与漫游，不是行政区划，也未描绘行政边界。
- 海岸、山势、楼高、道路、建筑数量和岛屿间距均经艺术化改动。渡轮、缆车和电车的运动仅表现城市生活，不代表真实班次、交通线路或导航路径。
- 全部几何由 Three.js 生成；普通楼体、树木、窗格与人物使用实例化。静态建筑按材质和 `landmarkId` 合并，仍保留每个地标的真实可识别 Mesh。

## 本模块自检

- 16 个地标均有实体 Mesh 和独立 ID，4 个浏览片区均有标签位置。
- 确定性种子 `20261018`；所有几何位置均为有限数值。
- 场景范围：`x=[-240,230]`、`z=[-160,170]`；底座底面 `y=-4.8`。
- 3 艘渡轮、1 辆山顶缆车、1 辆港岛电车随时间运动；发光材质遵循 `nightGlow` 合同。
- 本模块 Node 自检不替代整站浏览器验收；最终桌面、手机、夜景与部署情况以集成验证结果为准。
